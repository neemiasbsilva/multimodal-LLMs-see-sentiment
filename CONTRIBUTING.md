# Contributing to multimodal-LLMs-see-sentiment

First off, thank you for considering contributing to this repository! 

This project aims to advance research on how Multimodal Large Language Models (MLLMs) process and understand sentiment. Community contributions—whether they are bug fixes, documentation improvements, new evaluation metrics, or dataset integrations—are highly valued and help drive this research forward.

By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).

## How Can I Contribute?

### Reporting Bugs

If you find a bug in the code, a broken link, or an issue with reproducing the paper's results, please report it! 

Before creating bug reports, please check the existing issues to see if the problem has already been reported. If it hasn't, open a new issue and include:

* **A clear and descriptive title.**
* **Environment details:** Your OS, Python version, PyTorch version (if applicable), and CUDA version.
* **Steps to reproduce:** The exact commands or scripts you ran.
* **Expected vs. Actual results:** What you expected to happen and what actually happened (include full error tracebacks if applicable).

### Suggesting Enhancements

We welcome suggestions for new features, such as adding support for new MLLMs, expanding the benchmark datasets, or improving the evaluation pipeline.

* Open an issue explaining the enhancement.
* Provide a clear use case for why this would benefit the research community.
* If you have an idea of how to implement it, briefly outline your proposed approach.

### Contributing Code or Documentation

You don't need to be an expert to contribute! We welcome PRs for:
* **Documentation:** Fixing typos in the `README.md`, improving comments, or writing better tutorials.
* **Bug Fixes:** Resolving open issues.
* **Code Refactoring:** Improving code efficiency or readability without altering the core research methodology.
* **New Features:** Adding evaluation scripts or supporting new open-source models.
